Modo Desarrollador

En entornos de producción, el intercambio del código de autorización por el Access Token debe ocurrir del lado del servidor para proteger tu Client Secret. La PoC incluye este helper google-reviews-auth.php en la raíz: 

<?php
// 1. Credenciales de la App de Google
$clientId = getenv('GOOGLE_CLIENT_ID');
$clientSecret = getenv('GOOGLE_CLIENT_SECRET');
$redirectUri = 'http://' . $_SERVER['HTTP_HOST'] . strtok($_SERVER['REQUEST_URI'], '?');

// 2. Intercambio de Código por Access Token
if (isset($_GET['code'])) {
    $ch = curl_init();
    curl_setopt($ch, CURLOPT_URL, 'https://oauth2.googleapis.com/token');
    curl_setopt($ch, CURLOPT_POST, 1);
    curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query([
        'code' => $_GET['code'],
        'client_id' => $clientId,
        'client_secret' => $clientSecret,
        'redirect_uri' => $redirectUri,
        'grant_type' => 'authorization_code'
    ]));
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    $data = json_decode(curl_exec($ch), true);
    
    // El token resultante se guarda en la cookie / localStorage y se redirige
}

Mapeo de llamadas consecutivas requeridas para pintar las reseñas del perfil de negocio:

1. Listar Cuentas de Administrador:
GET https://mybusinessaccountmanagement.googleapis.com/v1/accounts
2. Listar Ubicaciones por Cuenta:
GET https://mybusinessbusinessinformation.googleapis.com/v1/accounts/{accountId}/locations?readMask=name,title,storefrontAddress
3. Listar Reseñas por Ubicación (Mantenido en v4):
GET https://mybusiness.googleapis.com/v4/accounts/{accountId}/locations/{locationId}/reviews
4. Responder a una Reseña Específica:
PUT https://mybusiness.googleapis.com/v4/accounts/{accountId}/locations/{locationId}/reviews/{reviewId}/reply
Payload: { "comment": "Mi respuesta..." }
